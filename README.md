# FABSTERsite – Angebote Datenpaket Hotel Dirsch

Fertig extrahierte Datenbasis für die Umsetzung der Angebotsübersicht und Angebotsdetailseiten.

## Enthalten

- `data/offers/angebote-dirsch.json` – strukturierte Datenquelle
- `data/offers/angebote-dirsch.csv` – schnelle Tabellenübersicht
- `content/angebote-dirsch-draft.php` – PHP-lesbarer Datenentwurf
- `docs/angebote-dirsch-datenuebersicht.md` – menschlich lesbare Übersicht
- `assets/img/dirsch/offers/*.webp` – normalisierte Angebotsbilder
- `MAGICA_PROMPT_ANGEBOTE.md` – Prompt für die Umsetzung

## Wichtig

Startseite bleibt Design-Master. Keine neuen CSS-Inseln. Angebote mit globalen FABSTERsite-Komponenten bauen.
